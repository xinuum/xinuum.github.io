# Generated website output

This public repository contains the reviewed, generated output for
[xinyujiajoseph.co.uk](https://xinyujiajoseph.co.uk/). The private Hugo source
and editorial workspace are maintained separately.

Every release records its private source commit, Hugo version and complete site
tree digest in `PROVENANCE.json`. The Pages workflow deploys only the `site/`
directory after the public-output audit succeeds.
